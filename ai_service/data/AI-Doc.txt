Medora AI Assistant Knowledge Base / قاعدة معرفة مساعد Medora
Purpose / الغرض: This is a bilingual, product-accurate support manual for an in-product AI assistant. It documents only workflows currently exposed in the Medora codebase. It is written in small, self-contained feature blocks so it can be split into JSON documents or RAG chunks.
هذا الدليل ثنائي اللغة ومبني على الخصائص الموجودة فعلياً في Medora. كل قسم مستقل قدر الإمكان ليصلح للتقسيم إلى عناصر JSON أو مقاطع RAG.
0. AI Operating Rules / قواعد تشغيل المساعد
Scope and safety / النطاق والسلامة
    • AR: يجيب المساعد عن كيفية استخدام المنصة، ولا يشخّص الأمراض ولا يصف أو يغيّر جرعات الأدوية. عند وجود أعراض خطرة أو طارئة، يجب توجيه المستخدم لطلب الرعاية الطارئة محلياً فوراً.
    • EN: The assistant explains how to use the platform. It must not diagnose conditions or prescribe/change medication doses. For severe or emergency symptoms, instruct the user to seek immediate local emergency care.
    • AR: لا تعد المستخدم بميزة غير متاحة. أمثلة غير متاحة حالياً في واجهة المريض: رفع ملفات طبية مستقلة، تعديل/إلغاء الموعد من حساب المريض، وتتبع طلبات الدواء من صفحة مريض مخصصة.
    • EN: Do not promise unavailable features. The current patient UI has no standalone medical-file upload, patient-side appointment edit/cancel control, or dedicated patient order-tracking page.
Answer template / قالب الإجابة
For each answer, identify the user role, name the page/menu/button exactly, give numbered steps, say what happens next, then provide an appropriate fallback.
في كل إجابة: حدّد نوع المستخدم، واذكر اسم الصفحة/القائمة/الزر، ثم الخطوات المرقمة وما الذي سيحدث بعدها، ثم حل بديل مناسب عند التعذر.

1. General Platform Overview / نظرة عامة على المنصة
Feature Name: Medora Platform Overview / نظرة عامة على Medora
Description / الوصف:
    • AR: Medora منصة صحية تجمع البحث عن الأطباء وحجز المواعيد، معلومات الأدوية والصيدليات، طلبات الأدوية، الروشتات، والمحتوى الصحي. كما توفر لوحات تشغيل للطبيب والصيدلية والإدارة.
    • EN: Medora is a healthcare platform that brings together doctor discovery and booking, medicine and pharmacy information, medicine orders, prescriptions, and health articles. It also provides operational dashboards for doctors, pharmacies, and administrators.
Who Can Use / من يمكنه الاستخدام: Guest, Patient, Doctor, Pharmacy, Admin / زائر، مريض، طبيب، صيدلية، مدير.
User roles and available areas / الأدوار والأقسام:
Role / الدور	Current areas / الأقسام المتاحة حالياً
Guest / زائر	Home, services, doctors, medicine search, pharmacies, articles, contact, sign in/up / الرئيسية، الخدمات، الأطباء، الأدوية، الصيدليات، المقالات، التواصل، التسجيل
Patient / مريض	Patient appointments, prescriptions, account settings / المواعيد، الروشتات، إعدادات الحساب
Doctor / طبيب	Overview, appointments, patients, prescriptions, reviews, clinics, profile, settings / لوحة ملخص، مواعيد، مرضى، روشتات، تقييمات، عيادات، ملف وإعدادات
Pharmacy / صيدلية	Overview, orders, inventory, prescriptions, customers, delivery, reviews, reports, profile, settings / ملخص، طلبات، مخزون، روشتات، عملاء، توصيل، تقييمات، تقارير، ملف وإعدادات
Admin / مدير	Overview, users, doctors, pharmacies, medicines, appointments, orders, articles, reviews, reports, lookup data, settings / لوحة الإدارة وكل أقسام الإشراف

Typical journey / رحلة المستخدم العامة:
    1. AR: افتح الصفحة الرئيسية واختر الخدمة من شريط التنقل أو صفحة الخدمات. EN: Open Home and choose a service from the navigation bar or Services page.
    2. AR: استعرض الأطباء أو الأدوية/الصيدليات أو المقالات بدون تسجيل عندما تسمح الصفحة بذلك. EN: Browse doctors, medicines/pharmacies, or articles without signing in where the page permits it.
    3. AR: عند الحاجة إلى إجراء محمي، سجّل الدخول أو أنشئ حساباً بالدور الصحيح. EN: When an action requires an account, sign in or create an account with the correct role.
    4. AR: أكمل ملفك إن ظهرت صفحة أكمل بياناتك؛ ثم نفّذ الإجراء مثل الحجز أو إنشاء الروشتة أو إدارة الطلب. EN: Complete your profile if the Complete Profile page appears, then perform the action such as booking, prescribing, or processing an order.
User Questions Examples / أمثلة أسئلة المستخدم:
    • "What can I do on Medora?" / "ماذا يمكنني أن أفعل في Medora؟"
    • "Which account type should I choose?" / "أي نوع حساب أختار؟"
AI Answer / إجابة جاهزة:
AR: يمكنك استخدام Medora للبحث عن طبيب وحجز موعد، البحث عن دواء أو صيدلية وطلب الأدوية المتاحة، والاطلاع على الروشتات والمقالات. اختر حساب مريض لاستخدام الخدمات الصحية، أو طبيب/صيدلية إذا كنت مقدم خدمة، بينما حساب Admin مخصص للإدارة.
EN: Medora lets you find doctors and book appointments, search medicines or pharmacies and order available medicines, and view prescriptions and articles. Choose Patient for healthcare services, Doctor/Pharmacy if you are a provider, and Admin for administration.

2. Patient Documentation / دليل المريض
Feature Name: Register a Patient Account / إنشاء حساب مريض
Description / الوصف: Creates a Patient account and starts email verification. / ينشئ حساب مريض ويبدأ التحقق عبر البريد الإلكتروني.
Who Can Use / من يمكنه الاستخدام: Guest / زائر.
Steps / الخطوات:
    1. AR: افتح إنشاء حساب / Sign Up واختر بطاقة مريض / Patient. EN: Open Sign Up and select the Patient role card.
    2. AR: اكتب الاسم الكامل، رقم الهاتف، البريد الإلكتروني، كلمة المرور وتأكيدها، ثم وافق على الشروط. EN: Enter full name, phone number, email, password and confirmation, then accept the terms.
    3. AR: يجب أن تحتوي كلمة المرور على 6 أحرف على الأقل، حرف كبير، حرف صغير، رقم، ورمز خاص. اضغط إنشاء حساب / Create Account. EN: The password needs at least 6 characters, uppercase, lowercase, number, and special character. Select Create Account.
    4. AR: تنتقل إلى صفحة OTP؛ أدخل رمز التحقق المرسل للبريد. EN: You are taken to the OTP page; enter the verification code sent by email.
    5. AR: بعد التحقق، قد تظهر صفحة أكمل بياناتك الشخصية / Complete Your Profile. أضف الاسم بالعربية والإنجليزية، الهاتف، تاريخ الميلاد، والملاحظات الطبية الاختيارية، ثم اضغط حفظ ومتابعة / Save & Continue. EN: After verification, Complete Your Profile may open. Add Arabic and English names, phone, date of birth, and optional medical notes, then select Save & Continue.
What happens next / ما الذي يحدث بعد ذلك: The account is verified and the profile data is saved; the user is redirected to Home. / يتم توثيق الحساب وحفظ الملف ثم العودة للصفحة الرئيسية.
User Questions Examples / أمثلة:
    • "How do I create a patient account?" / "إزاي أعمل حساب مريض؟"
    • "Why is my password rejected?" / "ليه كلمة السر مرفوضة؟"
AI Answer / إجابة جاهزة:
AR: من صفحة إنشاء حساب اختر مريض، وأدخل بياناتك ثم اضغط إنشاء حساب. أكمل رمز OTP الذي يصلك على البريد، وبعدها أكمل بيانات الملف الشخصي. تأكد أن كلمة المرور تحتوي على 6 أحرف على الأقل وحرف كبير وصغير ورقم ورمز خاص.
EN: On Sign Up, select Patient, enter your details, and select Create Account. Complete the email OTP, then finish your profile. Ensure the password has 6+ characters, uppercase, lowercase, a number, and a special character.
Feature Name: Sign In, Password Reset, and Sign Out / تسجيل الدخول واستعادة كلمة المرور وتسجيل الخروج
Description / الوصف: Authenticates existing users, supports Google sign-in, email reset, account logout and logout from all sessions. / يتيح دخول المستخدم الحالي، دخول Google، استعادة كلمة المرور بالبريد، والخروج من الجلسات.
Who Can Use / من يمكنه الاستخدام: Guest or signed-in user / زائر أو مستخدم مسجل.
Steps / الخطوات:
    1. Sign in / تسجيل الدخول: Open تسجيل الدخول / Sign In, enter email and password, then select تسجيل الدخول / Sign In. Google sign-in is available through Continue with Google. Facebook sign-in only displays “coming soon” and must not be described as available. / افتح صفحة الدخول، أدخل البريد وكلمة المرور واضغط الزر. يتوفر Google فقط؛ Facebook غير متاح بعد.
    2. Forgot password / نسيت كلمة المرور: From Sign In select نسيت كلمة المرور؟ / Forgot Password?, enter the account email, continue through the email-code verification screen, set the new password, and submit Reset Password. / من صفحة الدخول اختر نسيت كلمة المرور، أدخل البريد، تحقق بالرمز، ثم اختر كلمة مرور جديدة واضغط إعادة التعيين.
    3. Sign out / تسجيل الخروج: Use the user menu and choose تسجيل الخروج / Log out. The account API also supports Log out of all sessions for removing all active sessions. / من قائمة المستخدم اختر تسجيل الخروج. يوجد كذلك خروج من جميع الجلسات.
User Questions Examples / أمثلة:
    • "I forgot my password." / "نسيت كلمة المرور."
    • "Can I sign in with Facebook?" / "هل أقدر أدخل بفيسبوك؟"
AI Answer / إجابة جاهزة:
AR: لاستخدام كلمة مرور جديدة، افتح نسيت كلمة المرور؟ من صفحة الدخول، أدخل بريدك واتبع رمز التحقق ثم احفظ كلمة المرور الجديدة. تسجيل الدخول عبر Google متاح، أما Facebook فهو ظاهر كخدمة قادمة وليس متاحاً حالياً.
EN: To set a new password, select Forgot Password? on Sign In, enter your email, follow the verification-code flow, and save the new password. Google sign-in is available; Facebook is shown as coming soon and is not currently available.
Feature Name: Patient Profile and Medical Notes / ملف المريض والملاحظات الطبية
Description / الوصف: Updates personal information, date of birth, phone, bilingual names, medical notes, and password. / يحدّث البيانات الشخصية وتاريخ الميلاد والهاتف والاسمين والملاحظات الطبية وكلمة المرور.
Who Can Use / من يمكنه الاستخدام: Patient / مريض.
Steps / الخطوات:
    1. AR: من حساب المريض افتح إعدادات الحساب / Account Settings. EN: In the patient area, open Account Settings.
    2. AR: ضمن البيانات الشخصية / Personal Information عدّل الاسم بالعربية أو الإنجليزية أو الهاتف أو تاريخ الميلاد أو الملاحظات الطبية / Medical Notes. EN: Under Personal Information, edit Arabic/English name, phone, date of birth, or Medical Notes.
    3. AR: اضغط حفظ البيانات / Save Profile. تظهر رسالة نجاح بعد الحفظ. EN: Select Save Profile. A success message appears when saved.
    4. AR: لتغيير كلمة المرور اكتب الحالية والجديدة في قسم تغيير كلمة المرور / Change Password ثم اضغط تحديث كلمة المرور / Update Password. EN: To change the password, enter current and new password under Change Password, then select Update Password.
Important current limitation / قيد حالي مهم:
    • AR: الملاحظات الطبية نص داخل ملف المريض. لا توجد حالياً واجهة مستقلة لرفع تحاليل أو ملفات طبية أو إنشاء سجل مرضي تفصيلي منفصل.
    • EN: Medical notes are text in the patient profile. There is currently no standalone UI for uploading lab files/documents or creating a separate detailed medical-record file.
User Questions Examples / أمثلة:
    • "How do I change my phone number?" / "أغير رقم الهاتف إزاي؟"
    • "Can I upload a medical report?" / "هل أقدر أرفع تقرير طبي؟"
AI Answer / إجابة جاهزة:
AR: افتح إعدادات الحساب، عدّل رقم الهاتف أو أي بيانات أخرى داخل البيانات الشخصية ثم اضغط حفظ البيانات. يمكنك إضافة معلومات صحية كنص في الملاحظات الطبية. رفع ملفات طبية مستقلة غير متاح في الواجهة حالياً.
EN: Open Account Settings, edit your phone or other details in Personal Information, then select Save Profile. You can add health information as text in Medical Notes. Standalone medical-file uploads are not currently available in the UI.
Feature Name: Find a Doctor / البحث عن طبيب
Description / الوصف: Searches the public doctors directory and opens an individual doctor profile. / يبحث في دليل الأطباء العام ويفتح صفحة الطبيب.
Who Can Use / من يمكنه الاستخدام: Guest or Patient / زائر أو مريض.
Steps / الخطوات:
    1. AR: افتح الأطباء / Doctors من التنقل. EN: Open Doctors from navigation.
    2. AR: استخدم البحث واختيارات التخصص والموقع/المحافظة والمدينة والفلاتر الظاهرة في الصفحة لتضييق النتائج. EN: Use search, specialty, location/governorate/city, and the visible filters to narrow results.
    3. AR: راجع بطاقات النتائج؛ تعرض بطاقة الطبيب اسمه وتخصصه وبيانات العيادة والتقييم والرسوم أو المعلومات المتاحة. EN: Review result cards; they show the doctor’s name, specialty, clinic details, rating, fee, and available information.
    4. AR: اضغط على الطبيب لفتح صفحة تفاصيل الطبيب / Doctor Details. EN: Select a doctor to open Doctor Details.

    • AR: الاسم والصورة والتخصص والنبذة والخبرة/المؤهلات، بيانات العيادة والعنوان، سعر الكشف وسعر إعادة الكشف عند وجوده، التقييمات، وأزرار الحجز. البيانات المعروضة تعتمد على ما أدخله الطبيب وما هو متاح في ملفه.
    • EN: Name, photo, specialty, bio, experience/qualifications, clinic and address, consultation and re-consultation fee when available, reviews, and booking controls. Displayed fields depend on the doctor’s profile data.
User Questions Examples / أمثلة:
    • "How do I find a dermatologist near me?" / "إزاي ألاقي دكتور جلدية قريب مني؟"
    • "Where can I see doctor reviews?" / "أين أرى تقييمات الطبيب؟"
AI Answer / إجابة جاهزة:
AR: افتح الأطباء، اختر تخصص الجلدية ثم حدّد المحافظة أو المدينة واستخدم الفلاتر المتاحة. افتح بطاقة الطبيب لرؤية ملفه وبيانات العيادة والرسوم والتقييمات ثم استخدم زر الحجز إذا كان مناسباً لك.
EN: Open Doctors, select Dermatology, choose the governorate or city, and use the available filters. Open a doctor card to see the profile, clinic details, fees, and reviews, then use the booking button if suitable.
Feature Name: Book a Doctor Appointment / حجز موعد طبيب
Description / الوصف: Books an available clinic time with a doctor. / يحجز وقتاً متاحاً في عيادة الطبيب.
Who Can Use / من يمكنه الاستخدام: Signed-in Patient / مريض مسجل الدخول.
Steps / الخطوات:
    1. AR: من صفحة تفاصيل الطبيب اضغط حجز موعد / Book Appointment. إن لم تكن مسجلاً، سجّل الدخول أولاً. EN: On Doctor Details, select Book Appointment. Sign in first if requested.
    2. AR: في نافذة حجز موعد راجع اسم العيادة والتخصص والعنوان. اكتب الاسم بالكامل ورقم الهاتف. EN: In the Book Appointment dialog, review clinic, specialty, and address. Enter Full Name and Phone Number.
    3. AR: اختر يومًا من الأيام المتاحة ثم اختر وقتاً من المواعيد المتاحة. الأيام والأوقات تُحمّل من جدول الطبيب لفترة قادمة تصل إلى 21 يوماً. EN: Select an available day, then an available time. Days/times are loaded from the doctor’s schedule for up to the next 21 days.
    4. AR: أضف ملاحظات اختيارية ثم اضغط تأكيد الحجز / Confirm Booking. EN: Add optional Notes, then select Confirm Booking.
    5. AR: تظهر رسالة نجاح “تم الحجز بنجاح”. يُنشأ الموعد بحالة Pending / قيد الانتظار حتى يتم تأكيده. EN: A “Booking confirmed” message appears. The appointment is created as Pending until confirmed.
Appointment statuses / حالات الموعد:
Status	Arabic meaning / المعنى	Meaning / الوصف
Pending	قيد الانتظار	Created and awaiting confirmation / تم الإنشاء وينتظر التأكيد
Confirmed	مؤكد	Confirmed by the provider/admin / تم تأكيده من مقدم الخدمة أو الإدارة
Completed	مكتمل	Appointment marked completed / تم تسجيل انتهاء الموعد
Cancelled	ملغي	Appointment was cancelled / تم إلغاء الموعد

Follow-up / المتابعة:
    • AR: افتح مواعيدي / My Appointments داخل حساب المريض. توجد تبويبات القادمة / Upcoming والسابقة / Past، وتظهر الحالة والطبيب والتخصص والعيادة وموعد الزيارة والسبب إن أُدخل.
    • EN: Open My Appointments in the patient area. Use Upcoming and Past; the page shows status, doctor, specialty, clinic, time, and reason if provided.
    • AR: لا توفر واجهة المريض الحالية زرًا لتعديل أو إلغاء الموعد. عند الحاجة يجب التواصل مع العيادة/الدعم، ولا تقل للمستخدم إن هناك زر إلغاء في حسابه.
    • EN: The current patient UI has no appointment edit or cancel button. For a change/cancellation, direct the user to the clinic/support; do not tell them there is a patient-side cancel button.
User Questions Examples / أمثلة:
    • "How do I book a doctor?" / "ازاي احجز دكتور؟"

AI Answer / إجابة جاهزة:
AR: افتح صفحة الطبيب واضغط حجز موعد، ثم أدخل الاسم والهاتف واختر اليوم والوقت المتاحين واضغط تأكيد الحجز. ستجد الموعد في مواعيدي. حالة قيد الانتظار تعني أنه تم إنشاؤه وينتظر التأكيد. لا يوجد حالياً زر تعديل أو إلغاء داخل حساب المريض؛ تواصل مع العيادة أو الدعم لطلب ذلك.
EN: Open the doctor’s page and select Book Appointment, enter your name and phone, choose an available day/time, and select Confirm Booking. Find it under My Appointments. Pending means it was created and awaits confirmation. There is currently no patient-side edit/cancel button; contact the clinic or support to request a change.

3. Medicine and Pharmacy Documentation / دليل الأدوية والصيدليات
Feature Name: Search Medicines and View Medicine Details / البحث عن الأدوية وتفاصيلها

Who Can Use / من يمكنه الاستخدام: Guest or signed-in user / زائر أو مستخدم مسجل.
Steps / الخطوات:
    1. AR: افتح الأدوية / Medicine واكتب اسم الدواء في مربع البحث. تظهر اقتراحات وعمليات بحث شائعة وسجل بحث محلي. EN: Open Medicine and type a medicine name in search. Suggestions, popular searches, and local recent searches appear.
    2. AR: استخدم فلاتر التوفر والتوصيل والاستلام أو التصنيفات/الأعراض الموجودة بالواجهة عند الحاجة، ثم افتح بطاقة الدواء. EN: Use availability, delivery, pickup, category/symptom filters available in the interface, then open a medicine card.
    3. AR: في صفحة التفاصيل راجع التبويبات المتاحة: الاستخدامات، الجرعة المعروضة، التحذيرات، البدائل، والصيدليات التي يتوفر بها الدواء. EN: On the detail page, review available tabs: uses, displayed dosage, warnings, alternatives, and pharmacies that stock the medicine.

Medication safety rule / قاعدة سلامة الدواء:
AR: معلومات الاستخدام والتحذيرات والجرعات المعروضة معلومات مرجعية وليست وصفة فردية. لا ينبغي للمساعد اختيار دواء أو جرعة أو إيقاف علاج للمستخدم؛ يوجّه للصيدلي أو الطبيب عند الشك.
EN: Displayed uses, warnings, and dosage information are reference information, not an individualized prescription. The assistant must not select a medicine/dose or advise stopping treatment; refer to a pharmacist or doctor when uncertain.

EN: Open Medicine, type the medicine name, and select a result to view uses, warnings, alternatives, and available pharmacies. I can explain the displayed information, but I cannot determine a dose or prescribe personalized treatment; ask a doctor or pharmacist for that.

AR: يعني ذلك أن الحجز تم إنشاؤه وينتظر التأكيد. راقب مواعيدي لمعرفة حالته. إذا احتجت إلى تعديل أو إلغاء، تواصل مع العيادة أو الدعم لأن الواجهة الحالية لا توفر ذلك من حساب المريض.
EN: It means the booking was created and awaits confirmation. Check My Appointments for its status. For a change/cancellation, contact the clinic or support because the current patient UI does not provide that control.
Problem: Medicine is not found / لا أجد الدواء
Possible reasons / الأسباب المحتملة: Different spelling/name, catalogue does not contain it, or no pharmacy has it in stock. / اختلاف الاسم أو الكتابة، الدواء غير موجود بالكتالوج، أو لا يتوفر في الصيدليات.
AI Response / إجابة المساعد:
AR: جرّب الاسم التجاري أو العلمي أو كتابة جزء من الاسم، وراجع الاقتراحات. إذا لم تظهر نتيجة، فهذا لا يثبت عدم وجود الدواء طبياً؛ يعني فقط أنه غير موجود في نتائج المنصة الحالية. اسأل الصيدلي عن البديل المناسب ولا تغيّر الدواء بنفسك.
EN: Try the brand name, generic name, or part of the name and check suggestions. No result does not prove the medicine does not exist medically; it only means it is absent from current platform results. Ask a pharmacist about a suitable alternative and do not switch medicines on your own.
Problem: Cannot place medicine order / لا أستطيع إتمام طلب الدواء
Possible reasons / الأسباب المحتملة: User not signed in, cart is empty, contact fields missing, delivery address missing for delivery, pharmacy/item unavailable, or checkout error. / المستخدم غير مسجل، السلة فارغة، بيانات التواصل ناقصة، عنوان التوصيل ناقص، الصيدلية/الصنف غير متاح، أو خطأ في الإتمام.
AI Response / إجابة المساعد:
AR: تأكد أن السلة تحتوي على دواء، واختر توصيل أو استلام. للتوصيل أدخل الاسم والهاتف والعنوان، ثم أعد المحاولة. إذا فشل الطلب بعد ذلك، راجع توفر الصيدلية أو جرّب صيدلية أخرى.
EN: Make sure the cart has an item and choose Delivery or Pickup. For delivery, enter name, phone, and address, then retry. If it still fails, check pharmacy availability or try another pharmacy.
Problem: Pharmacy cannot update an order / الصيدلية لا تستطيع تحديث الطلب
Possible reasons / الأسباب المحتملة: Trying to use an action not allowed for the current status, session/role issue, or connection error. / محاولة إجراء غير مسموح للحالة الحالية، مشكلة صلاحية/جلسة، أو اتصال.
AI Response / إجابة المساعد:
AR: افتح تفاصيل الطلب وتحقق من حالته الحالية. اتبع الأزرار المتاحة بالتسلسل: Pending → Accepted → Preparing → ReadyForPickup أو OutForDelivery → Delivered. لا يمكن تخطي حالة عبر الواجهة.
EN: Open order details and check its current status. Follow the available sequence: Pending → Accepted → Preparing → ReadyForPickup or OutForDelivery → Delivered. The UI does not allow skipping states.
Problem: Verification was rejected or remains pending / التحقق مرفوض أو ما زال معلقاً
Possible reasons / الأسباب المحتملة: Documents are incomplete/unclear, submitted information needs review, or admin has not processed it yet. / مستندات ناقصة أو غير واضحة، البيانات تحتاج مراجعة، أو لم تعالجها الإدارة بعد.
AI Response / إجابة المساعد:
AR: راجع سبب الرفض إن ظهر، وحدّث البيانات أو المستندات المطلوبة ثم أعد الإرسال وفق ما تسمح به الواجهة. إذا كانت الحالة معلقة فقط، فهي بانتظار مراجعة الإدارة ولا تعني القبول أو الرفض بعد.
EN: Review the rejection reason if shown, update the required data/documents, and resubmit as the UI allows. If the status is only pending, it awaits admin review and is neither approved nor rejected yet.
Problem: User cannot see a prescription / لا أرى الروشتة
Possible reasons / الأسباب المحتملة: Appointment is not completed, doctor has not created/saved the prescription, wrong account, or loading error. / الموعد غير مكتمل، الطبيب لم ينشئ/يحفظ الروشتة، الحساب خاطئ، أو خطأ تحميل.
AI Response / إجابة المساعد:
AR: افتح روشتاتي بالحساب الذي حجز الموعد. الروشتات تظهر بعد إتمام الموعد وحفظ الطبيب لها. إذا كان الموعد مكتملًا ولا تظهر الروشتة، أعد تحميل الصفحة ثم تواصل مع العيادة أو الدعم.
EN: Open My Prescriptions using the account that booked the appointment. Prescriptions appear after the appointment is completed and the doctor saves them. If the appointment is completed and it is still missing, reload and contact the clinic or support.
